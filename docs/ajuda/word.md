# Word - Angerô — Ajuda

Editor de textos do **Office Angerô**, com a faixa de opções, os estilos e os atalhos do Microsoft Word.
Abre e salva **.docx** (também abre .doc, .odt, .rtf, .txt e .md).

## O básico

- **Novo / Abrir / Salvar:** guia **Arquivo** (ou Ctrl+N, Ctrl+O, Ctrl+S). Salvar como .docx mantém o arquivo
  compatível com o Microsoft Word.
- **Exportar PDF:** Arquivo › Exportar › PDF.
- **Estilos:** guia **Página Inicial** › Estilos (Título 1, Título 2, Normal…). Usar estilos permite criar o
  **sumário** automático (guia Referências › Sumário).
- **Tabelas, imagens e formas:** guia **Inserir**.
- **Margens, orientação e colunas:** guia **Layout**.
- **Controlar alterações e comentários:** guia **Revisão**.
- **Mala direta:** guia **Correspondências**.

## Dicas

- Ctrl+Z desfaz, Ctrl+Y refaz. Ctrl+F procura no texto.
- O idioma da tela segue o do Windows; dá para trocar em Arquivo › Opções.

Outras dúvidas: fale com o TI do Grupo Angerô.
